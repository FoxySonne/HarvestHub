# HarvestHub

Перед выпуском изменений союзного штаба примените SQL-миграции из [supabase/migrations](supabase/migrations) по порядку сначала в тестовой базе со схемой HarvestHub. Проверьте права и удаление только на тестовом союзе. На рабочей базе сначала включите нужную схему, затем публикуйте соответствующий интерфейс.

Отключённые вкладки задаются в [настройке разделов штаба](js/alliance/headquarters-sections.js). Их данные сохраняются.

Добавление карт описано в [инструкции к каталогу карт штатов](data/state-maps/README.md).
