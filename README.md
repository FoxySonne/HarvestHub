# HarvestHub

Новая адаптивная оболочка. Оформление основано на HarvestHub-test:
исходные палитры, JetBrains Mono, заголовок, меню и характер карточек.
Разметка, расположение блоков и управление интерфейсом написаны заново.

## Что сейчас работает

- Навигация между разделами, прямые ссылки и кнопки назад/вперёд браузера.
- Меню и полезная панель на телефоне и планшете.
- Постоянные боковые панели на широком экране.
- Тёмная и светлая темы; выбор сохраняется в браузере, если хранение разрешено.
- Местные и UTC-часы.

Калькуляторы, игровые расписания, аккаунты, базы данных и синхронизация
не подключены. Их будущие разделы показывают явное сообщение «Скоро».
Перевод времени показан как статичный образец без ввода и расчётов.

## Файлы

- `index.html` — оболочка и содержимое разделов.
- `styles.css` — исходные цвета и новая вёрстка, начиная с телефона.
- `theme.js` — применение сохранённой темы до отрисовки страницы.
- `app.js` — только управление оболочкой и обычные часы.
- `CNAME` — привязка harvesthub.ru; сохранять при дальнейших изменениях.

Пакеты и сборка не нужны. Можно открыть `index.html` в браузере.
Публикация: GitHub Pages, ветка `Основной`, корень репозитория.
Шрифт загружается из Google Fonts; без сети используется моноширинный шрифт системы.

## Как расширять

Добавляйте по одному разделу в существующую оболочку. Сохраняйте переменные
палитры и стили общих элементов. Новые таблицы и формы нужно отдельно
проверять с реальными длинными значениями и заполненными данными.

Базовая вёрстка работает на телефоне. На 40rem расширяются сетки,
на 56rem появляется постоянное левое меню, на 80rem — постоянная правая панель.
Содержимое имеет максимальную ширину 100rem, чтобы не растягиваться без границ
на больших мониторах. Панели остаются доступны при маленькой высоте окна.
